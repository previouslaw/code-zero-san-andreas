# Code Zero: San Andreas — FiveM starter kit

This is an organized Windows-first starter kit for a private FiveM roleplay server. It uses the QBCore txAdmin recipe as its framework base and includes one small Code Zero resource with server information, rules, a welcome message, and a rate-limited player report command.

The kit does not contain FXServer, GTA V files, a database, or third-party framework resources. txAdmin installs the current QBCore resources from their maintainers. No paid scripts are included.

## What is here

- `server-data/resources/[local]/czs_basics` — the Code Zero commands and settings you can edit.
- `server-data/server.cfg.additions.cfg` — the two lines to add to the QBCore-generated server config.
- `assets/code-zero-san-andreas-logo.png` — the updated logo.
- `assets/server-icon.png` — a 96 × 96 PNG for the FiveM server listing.
- `docs/` — Windows setup, a map of the script folders, and a short learning guide.
- `docs/feature-setup.md` — where the requested roleplay systems come from and how to organize them.

## Start here

Read [`docs/first-run-windows.md`](docs/first-run-windows.md) first. In short, you will install FXServer and txAdmin, deploy QBCore from its txAdmin recipe, then copy the local resource and add the config lines from this kit. The Discord command is already set to your invite.

Keep your Cfx license key and database password in txAdmin or your local server configuration. Do not put secrets in a public repository, screenshots, or chat.

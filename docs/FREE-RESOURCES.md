# Free resource register

The recipe installs public, free-to-download resources from their upstream GitHub repositories. No paid script, paid vehicle/map pack, Tebex asset, or paid container is included in this project. Upstream repositories keep their own licenses and terms; review them before changing, redistributing, or monetizing a server.

| Layer | Upstream | Examples included by the recipe |
| --- | --- | --- |
| Framework and install recipe | [QBCore](https://github.com/qbcore-fivem/qb-core), [QBCore txAdmin recipe](https://github.com/qbcore-fivem/txAdminRecipe) | Core, database schema, character creation, jobs and framework utilities |
| Base FiveM resources | [Cfx server data](https://github.com/citizenfx/cfx-server-data) | Chat, spawn manager, session manager, base events and default resources |
| Database | [oxmysql](https://github.com/overextended/oxmysql) | MySQL/MariaDB driver used by QBCore |
| Voice | [pma-voice](https://github.com/AvarianKnight/pma-voice), [QBCore radio](https://github.com/qbcore-fivem/qb-radio) | Proximity voice and radio |
| QBCore gameplay | [QBCore resources](https://github.com/orgs/qbcore-fivem/repositories) | Police, EMS, inventory, shops, phone, banking, apartments, houses, garages, vehicles, clothing, admin menu, crafting, racing, recycling, taxi, bus, tow, garbage, diving, and more |
| QBCore supporting resources | [PolyZone](https://github.com/qbcore-fivem/PolyZone), [progressbar](https://github.com/qbcore-fivem/progressbar), [interact-sound](https://github.com/qbcore-fivem/interact-sound), [bob74_ipl](https://github.com/qbcore-fivem/bob74_ipl) | Shared zones, UI progress, sound and map interiors |
| Code Zero custom gameplay | This repository | Fictional 911/311 dispatch and City Hall courier route |

The recipe follows the current QBCore recipe's upstream branch/release references, so dependencies may update over time. Back up the database and review upstream changes before refreshing an established live server. The free software does not make physical hosting, a database service, or internet access free.

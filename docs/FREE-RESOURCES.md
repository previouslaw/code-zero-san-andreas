# Free resource register

The official QBCore txAdmin recipe installs public, free-to-download resources. This private repository adds the custom Code Zero resources after that install. No paid script, paid vehicle/map pack, Tebex asset, or paid container is included. Upstream repositories retain their own licenses and terms; review them before changing, redistributing, or monetizing a server.

| Layer | Upstream | Examples |
| --- | --- | --- |
| Framework and installer | [QBCore](https://github.com/qbcore-fivem/qb-core), [QBCore txAdmin recipe](https://github.com/qbcore-fivem/txAdminRecipe) | Core, database schema, character creation, jobs, and framework utilities |
| Base FiveM resources | [Cfx server data](https://github.com/citizenfx/cfx-server-data) | Chat, spawn manager, session manager, base events, and defaults |
| Database | [oxmysql](https://github.com/overextended/oxmysql) | MySQL/MariaDB driver used by QBCore |
| Voice | [pma-voice](https://github.com/AvarianKnight/pma-voice), [QBCore radio](https://github.com/qbcore-fivem/qb-radio) | Proximity voice and radio |
| QBCore gameplay | [QBCore resources](https://github.com/orgs/qbcore-fivem/repositories) | Police, EMS, inventory, shops, phone, banking, housing, garages, clothing, admin menu, crafting, races, recycling, taxi, bus, tow, garbage, diving, and more |
| Supporting resources | [PolyZone](https://github.com/qbcore-fivem/PolyZone), [progressbar](https://github.com/qbcore-fivem/progressbar), [interact-sound](https://github.com/qbcore-fivem/interact-sound), [bob74_ipl](https://github.com/qbcore-fivem/bob74_ipl) | Shared zones, progress UI, sound, and map interiors |
| Code Zero custom gameplay | This repository | Fictional 911/311 dispatch and the City Hall courier route |

QBCore resources are installed from their current upstream branch or release references, so dependencies can change over time. Back up the database and review upstream changes before refreshing an established server. Free software does not make physical hosting, a database service, or internet access free.

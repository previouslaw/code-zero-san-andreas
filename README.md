# Code Zero: San Andreas

![Code Zero: San Andreas logo](assets/server-icon.png)

A custom community roleplay server package for FiveM built on QBCore. The public QBCore recipe installs the free framework stack; the local installer in this private repository adds the Code Zero resources and logo without exposing the repo or a GitHub token.

## Included

- QBCore character creation, spawn selection, inventory, shops, banking, phone, housing, apartments, garages, clothing, vehicles, and admin tools.
- Police and EMS roleplay, plus civilian activities such as taxi, bus, tow, garbage, recycling, trucking, diving, crafting, and legal/illegal activities.
- pma-voice and QBCore radio resources.
- Custom Code Zero dispatch: `/911 message` sends an alert to on-duty police and EMS; `/311 message` sends an alert to mechanics and tow.
- Custom City Hall courier route: press **E** at the Code Zero clerk, deliver five parcels, and collect a server-validated cash payout. Use `/cancelroute` to stop a route.
- Code Zero server branding using the supplied logo.

No paid scripts, paid assets, Tebex dependency, or paid container are included. Upstream resources are installed from their public repositories and remain subject to their own licenses. A machine/server host and database still need to be available; whether those cost money depends on where you run them.

## Install

1. Install FXServer and open txAdmin. Create a new server profile.
2. In txAdmin, choose **Popular Recipes → Custom Recipe** and use the public QBCore recipe:  
   `https://raw.githubusercontent.com/qbcore-fivem/txAdminRecipe/main/qbcore.yaml`
3. Enter the free Cfx.re server key and MySQL-compatible database connection in txAdmin's private setup prompts. Run the recipe and wait for QBCore resources and database tables to install.
4. Get this private repository onto the machine that holds the txAdmin server profile, using your normal authenticated GitHub access.
5. Stop the server. From this repository, run the post-install script against the folder containing the generated `server.cfg` and `resources` directory:

   **Windows PowerShell**
   ```powershell
   .\scripts\install-codezero.ps1 -ServerDataPath "C:/FXServer/txData/CodeZero"
   ```

   **Linux**
   ```bash
   bash scripts/install-codezero.sh /path/to/txData/CodeZero
   ```

6. Start the server in txAdmin. Configure the public server name, description, tags, and banner in the Cfx Portal.

The script copies the custom resources and server icon, then adds or updates only the `ensure [codezero]` and `load_server_icon` lines. It preserves the key, database settings, and other server configuration already generated by txAdmin.

## First session

- Create a character at the multicharacter screen and choose a spawn.
- Use QBCore City Hall and job resources to choose activities and get started.
- For a custom delivery route, visit the clerk outside City Hall at `(-266, -963, 31)`, press **E**, and follow the GPS route.
- Use `/911` or `/311` with a short message to send a fictional in-game dispatch alert. These are game roleplay commands, not real emergency services.

## Security and updates

- Keep the Cfx key and database password in txAdmin's setup inputs or a private local config. Never commit them or post them in chat.
- Run the installer after the QBCore recipe has generated the server profile. It does not replace `server.cfg`.
- Grant staff permissions through txAdmin's Admin Manager.
- Back up the QBCore database before updating upstream resources. The QBCore recipe follows upstream branch/release references, which can change over time.
